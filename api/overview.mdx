The HealthIA API is a FastAPI-based REST API that accepts patient symptoms and returns a predicted medical diagnosis using a trained XGBoost model.

## Base URL

```
http://127.0.0.1:8000
```

The frontend reads the base URL from the `VITE_API_BASE_URL` environment variable. If the variable is not set, it defaults to `http://127.0.0.1:8000`.

## Response format

All endpoints return JSON. No authentication is required.

## CORS

By default, the API allows requests from:

- `http://127.0.0.1:5173`
- `http://localhost:5173`
- Any domain matching `*.up.railway.app`

You can extend the allowed origins using environment variables:

| Variable | Description |
| --- | --- |
| `FRONTEND_URL` | A single additional allowed origin |
| `FRONTEND_URLS` | Comma-separated list of additional allowed origins |
| `ALLOW_ALL_ORIGINS` | Set to `true` to allow all origins (`*`) |

## Interactive docs

FastAPI automatically generates interactive API documentation:

- **Swagger UI** — `http://127.0.0.1:8000/docs`
- **ReDoc** — `http://127.0.0.1:8000/redoc`

## Endpoints

| Method | Path | Description |
| --- | --- | --- |
| `GET` | `/` | Health check — returns a welcome message |
| `GET` | `/predict/` | Predict a diagnosis from a list of symptoms |
