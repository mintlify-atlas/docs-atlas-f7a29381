## Prerequisites

Before you begin, make sure you have the following installed:

- **Python 3.10+** — required to run the FastAPI backend
- **Node.js 18+** — required to run the Vite frontend
- **Git** — to clone the repository

<Steps>

<Step title="Clone the repository">

Clone the HealthIA repository to your local machine.

<CodeGroup>

```bash HTTPS
git clone https://github.com/your-org/healthia.git
cd healthia
```

```bash SSH
git clone git@github.com:your-org/healthia.git
cd healthia
```

</CodeGroup>

</Step>

<Step title="Set up the backend">

Install the Python dependencies and start the FastAPI server.

<CodeGroup>

```bash Install dependencies
pip install -r requirements.txt
```

```bash Start the server
uvicorn main:app --reload
```

</CodeGroup>

Run both commands from the `HEALTHIA/` directory. The API will be available at `http://127.0.0.1:8000`.

To confirm the backend is running, open `http://127.0.0.1:8000` in your browser. You should see:

```json
{ "Message": "Welcome to HealthIA API" }
```

</Step>

<Step title="Set up the frontend">

Open a new terminal, navigate to the `frontend/` directory, and run the following commands.

<CodeGroup>

```bash Install dependencies
npm install
```

```bash Copy environment file
cp .env.example .env
```

```bash Start the dev server
npm run dev
```

</CodeGroup>

The `.env.example` file already contains the correct value for local development:

```bash .env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

No changes to `.env` are needed for a local setup.

<Note>
  The backend must be running before you start the frontend. The React app calls `http://127.0.0.1:8000` on load — if the backend is not running, diagnosis requests will fail.
</Note>

</Step>

<Step title="Open the app">

With both servers running, open your browser and navigate to:

```
http://localhost:5173
```

You should see the HealthIA interface. Enter a set of symptoms and click **Diagnose** to receive an AI-generated diagnosis prediction.

</Step>

</Steps>
