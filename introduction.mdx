# Welcome to HealthIA

HealthIA is an intelligent diagnostic assistant that uses machine learning to predict medical conditions from natural-language symptom descriptions. You describe how you feel — HealthIA returns a probable diagnosis in seconds.

<Warning>
  HealthIA is a research and educational tool. It is **not a substitute for professional medical advice**. Always consult a qualified healthcare provider for any medical concerns.
</Warning>

## How it works

HealthIA combines a FastAPI backend with a trained XGBoost classifier to analyze symptoms and return predicted diagnoses. The frontend is a React + TypeScript single-page application that communicates directly with the API.

## Tech stack

| Layer | Technology |
|-------|------------|
| Backend | Python 3, FastAPI, Uvicorn |
| ML Model | XGBoost, scikit-learn, TF-IDF vectorization |
| Frontend | React 18, TypeScript, Vite, Tailwind CSS |
| Deployment | Railway (backend), Vite preview / static host (frontend) |

## Supported conditions

HealthIA can predict the following 20 medical conditions based on symptom patterns:

<AccordionGroup>
  <Accordion title="Autoimmune & inflammatory">
    Lupus, Rheumatoid Arthritis, Multiple Sclerosis, Sjögren's Syndrome, Myasthenia Gravis
  </Accordion>
  <Accordion title="Neurological & degenerative">
    Alzheimer's Disease, Parkinson's Disease, Lateral Sclerosis (ALS), Wilson's Disease
  </Accordion>
  <Accordion title="Metabolic & endocrine">
    Type 1 Diabetes, Hyperthyroidism, Hypothyroidism
  </Accordion>
  <Accordion title="Infectious & tick-borne">
    Lyme Disease, Rocky Mountain Spotted Fever (Febre Maculosa)
  </Accordion>
  <Accordion title="Gastrointestinal">
    Crohn's Disease, Porphyria
  </Accordion>
  <Accordion title="Chronic & systemic">
    Fibromyalgia, Chronic Fatigue Syndrome, Sarcoidosis, Sickle Cell Anemia
  </Accordion>
</AccordionGroup>
